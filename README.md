### 🍬 这个博客是什么

- 记录技术思考与生活点滴，也放一些自己做的小东西[reference:2]。
- 内容很杂：有 Steam 工具链、Android 内核相关的东西，也有 `Online/game` 下面纯粹好玩的小游戏。
- 没有框架，没有构建步骤，就是**手写的静态 HTML / CSS / JS**，打开就能跑。

### 🗂️ 里面有什么

| 位置 | 说明 |
|---|---|
| **首页** | 博客主入口，[meowrc.github.io](https://meowrc.github.io) |
| **`Online/`** | 在线小工具 / 小游戏的入口目录 |
| **`Online/game/`** | 小游戏合集 |
| **`assets/`** | 静态资源 |
| **多入口兼容** | `index.html` / `index-apple.html` / `index-ie.html`，针对不同浏览器做了分流[reference:3] |

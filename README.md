### 🍬 这个博客是什么

- 记录技术思考与生活点滴，也放一些自己做的小东西。
- 内容很杂：有 Steam 工具链、Android 内核相关的东西，也有 `online/game` 下面纯粹好玩的小游戏（比如函数棋）。
- 没有框架，没有构建步骤，就是**手写的静态 HTML / CSS / JS**，打开就能跑。

### 🗂️ 里面有什么

| 位置 | 说明 |
|---|---|
| 🏠 **首页** | 博客主入口 · [meowrc.github.io](https://meowrc.github.io) |
| 📂 **`online/`** | 在线枢纽页，进入后分为 **下载 / 音乐 / 游戏** 三个分区 |
| ↳ `online/download/` | 下载与工具合集 |
| ↳ `online/music/` | 音乐相关的在线内容 |
| ↳ `online/game/` | 小游戏合集（如「函数棋」） |
| 🎨 **`assets/`** | 样式与脚本等静态资源（含按页外置的 `index*.css` 与共享的 `online-base.css`） |
| 🧭 **多入口兼容** | `index.html` / `index-apple.html` / `index-legacy.html` / `index-ie.html`，针对不同浏览器做了分流 |

### 🎮 在线分区

访问 [meowrc.github.io/online/](https://meowrc.github.io/online/) 后会看到三个入口，按需进入：

- **下载（Download）**：各类下载与实用工具。
- **音乐（Music）**：音乐相关的在线内容。
- **游戏（Game）**：浏览器里直接玩的小游戏。

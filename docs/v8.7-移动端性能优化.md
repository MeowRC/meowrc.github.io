## 一、瓶颈分析

对现有资源做静态清点后，普通安卓移动设备（未开启「减少动效」）仍承担：

| 类别 | 实测数量 | 影响 |
|---|---|---|
| `aesthetic.css` 中 `filter:blur()` 声明 | 16 | 4 个 `blur(60px)` 极光层、`blur(50px)` 光球持续动画，大面积 GPU 重绘 |
| 持续动画声明 | 13 | 全屏装饰层 30~48s 无限循环 |
| 页面 CSS 中 `backdrop-filter` | 12 | 固定导航栏在每帧滚动时重算全屏模糊 |
| `aesthetic.js` 事件监听 | 22 | tilt / magnet / ripple / cursor / scroll 弹簧等 |
| `aesthetic.js` rAF 弹簧、轮询 | 4 + 1 | `setInterval(180ms)` loader 轮询最多 18s |
| `mix-blend-mode` 全屏噪点层 | 2 | `.fx-grain` 使用 SVG `feTurbulence` + 混合模式 |
| `[data-reveal]` 的 `filter:blur(6px)` 转场 | 全站 | 滚动进入视口时 blur 动画 |
| v8.5 光效层 | 大屏安卓平板可命中 | 三层径向渐变 + 固定层漂移 |

已有的 `@media (max-width:720px)` 只关闭了 `.fx-grain` 并减弱极光；完整装饰层仅在 `prefers-reduced-motion:reduce` 下才被禁用，覆盖面不足。

## 二、优化方案：条件式渲染预算

新增两个文件，全部以 `<html data-perf="mobile">` 为门控：

### `assets/mobile-perf.js`（ES5，零依赖，无监听器 / 定时器）

在 `<head>` 的 charset 之后**同步执行**，先于所有其它脚本：

- 仅当 UA 含 `Android` 且（`pointer: coarse` 或 UA 含 `Mobile|Tablet|Silk|Kindle`）时打 `data-perf="mobile"`；
- Android TV / 桌面版（精细指针且无 Mobile 标记）、iOS、Windows/macOS 全部不受影响；
- 低配设备（核心 ≤4、内存 ≤3GB、`saveData` 或 2G/3G）额外打 `data-perf-tier="low"`。

### `assets/mobile-perf.css`（放在 `</head>` 最后，优先级最高）

1. **隐藏昂贵装饰层**：`.fx-aurora`、`.fx-grain`、`.fx-hero-orb`、`.fx-progress`、`.fx-sweep`、`.fx-ripple`、光标、粒子，以及 v8.5 的 `body::before` / `.navbar::before` 光效层；
2. **停用持续动画**：标题扫光、微光脉动、caret、入场动画；首屏文本改为 `opacity:1` 静态可见，无需等待动画；
3. **内容优先**：`[data-reveal]` 强制 `opacity:1`、`filter:none`、`transform:none`、`transition:none`，不再依赖 IntersectionObserver / classList 成功执行；
4. **移除 `backdrop-filter`**：导航栏与主题控件改用不透明背景（暗色主题有对应色值），消除滚动时的全屏模糊重算；
5. **去掉阴影、hover 位移与渐变文字滤镜**：触屏无 hover，这些只消耗绘制；
6. **收敛 `will-change`**：释放多余合成层，降低显存压力；
7. **低配档**：进一步关闭剩余转场，把 `background-clip:text` 标题改为实色，避免渐变重绘；loader 仍由页面自身 `setTimeout` 移除，禁用其转场安全；
8. `prefers-reduced-motion` 二次兜底。

### JS 短路

`aesthetic.js` 与 `glow-fx.js` 的顶层守卫增加 `data-perf="mobile"` 判断。**安卓设备不再创建装饰 DOM、不绑定 22 个监听、不启动 rAF 弹簧与 loader 轮询**，这是本次最大的运行时收益。各页面内联的基础交互（主题切换、移动菜单、展开卡片、回到顶部）保留。

## 三、实测对比（headless Edge，Android 13 / Pixel 7 UA，390×844）

| 指标 | 桌面（优化前路径） | 安卓移动（优化后） |
|---|---|---|
| `data-perf="mobile"` | 无 | **有** |
| `data-glow="on"` | 有 | **无**（光效短路） |
| `.fx-aurora` / `.fx-grain` / `.fx-sweep` DOM | 全部生成 | **均不生成** |
| 首页渲染后 DOM 长度 | 22,626 字符 | **19,364 字符**（−14.4%，装饰 DOM 未生成） |

> DOM 长度为同一 `index.html` 的 `--dump-dom` 结果，具有可比性；截图文件大小受视口尺寸影响较大，不作为性能量化依据。

截图复核：安卓端导航栏品牌、`MeowRc` / `Blog` 主标题、在线枢纽页标题与三张分项目入口卡片均完整可见，无空白区域、无破版；桌面端装饰层保持原样。

## 六、已知限制

1. **无真实安卓真机与帧率采样**。验证采用 UA + 视口模拟的真实渲染、`data-perf` 标记与装饰层 DOM 对比、静态预算量化；帧率改善幅度需在中低端真机上用性能面板实测。
2. 优化只作用于识别为安卓手持设备的情况；iOS 移动设备仍按原有路径渲染（本次需求范围为安卓）。
3. 安卓移动端会有意失去 v8.3 / v8.5 的极光、噪点、光效、卡片倾斜与视差等装饰动效；内容、导航、下载、主题切换与全部入口功能不受影响。
4. 函数棋主体页仍不接入该层（独立 Canvas 应用，资源与交互体系不同）。
5. 本次未创建 Git tag / GitHub Release；如需发布 v8.7 可随时补上。

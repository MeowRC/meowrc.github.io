## 一、iOS 适配现状与缺口

核查发现已有适配并不完整：

| 位置 | 原有状态 |
|---|---|
| `index-apple.html` / `online/index-apple.html` | 已有 `viewport-fit=cover`、Apple Web App meta |
| `assets/index-apple.css` | 已为根 iOS 变体的 `.navbar` / `.main` / `.footer` / `.to-top` / `.nav-links` 写有 `constant()` + `env()` 安全区规则 |
| `assets/online-base.css`（7 个 online 页共用） | **完全没有** `env(safe-area-inset-*)` |
| `online/download/`、`music/`、`game/` | 无变体页，**没有** `viewport-fit=cover`，iOS 用户会直接进入 |
| `online/game/index.html` 的 `.theme-ctl` / `.wrap` | 固定定位元素未避开状态栏与 Home Indicator |

因此 iPhone X 及以上在在线分区会出现固定导航被状态栏/刘海压住、悬浮按钮落入 Home Indicator 区域、横屏内容贴近刘海侧等问题。

## 二、适配方案

### `assets/ios-adapt.js`（ES5，`<head>` 内同步）

- 识别 iPhone / iPad / iPod，以及 iPadOS 13+ 伪装为桌面 UA 的设备（`platform === 'MacIntel' && maxTouchPoints > 1`），打 `data-ios="1"`；
- **通过运行时 `getComputedStyle` 读取真实 `env(safe-area-inset-top/bottom)` 值**判定全面屏，而非硬编码机型尺寸：竖屏顶部 inset ≥ 44px（刘海 / 灵动岛）或底部 inset > 0（Home Indicator）时打 `data-ios-notch="1"`；
- 该脚本必须排在 viewport meta **之后**、body 脚本之前，否则 `env()` 尚未生效会误判为普通 iPhone。本次已按此顺序接入并在验证脚本中断言。

### `assets/ios-adapt.css`（全部规则以 `html[data-ios="1"]` 门控）

- 固定导航栏：`height` 与 `padding-top` 叠加 `safe-area-inset-top`，`constant()` 兼容 iOS 11.0~11.2；`.navbar-inner` 左右避开横屏刘海；
- 下拉菜单：定位到加高后的导航栏下方，底部补 Home Indicator 高度；
- Hero / 主内容 / 页脚：顶部、左右、底部分别叠加对应 inset，使用长手属性保留原有 `padding-top`；
- 悬浮控件：`.to-top` 与 game 页 `.theme-ctl` 避开底部与顶部安全区；game 页 `.game-topnav` / `.wrap` 单独处理；
- iPhone X+ 额外：`min-height:92dvh` 规避地址栏收起时的 `100vh` 跳变；禁用最昂贵的全屏 `feTurbulence` 噪点层（`.fx-grain`）并释放 `.fx-aurora i` 的 `will-change`，其余视觉保持；
- 所有 `env()` 带 `0px` 回退值，非 iOS 或不支持安全区的引擎保持原几何。

### 全站接入

11 个站点页面的 viewport meta 统一补 `viewport-fit=cover`，并各增加 head 内探测脚本与 `<head>` 末尾的安全区样式。`ppt/1` 等纯跳转页不接入（立即跳转，无渲染界面）。

## 三、ppt/1 跳转更新

`ppt/1/index.html` 原使用 2026-10-31 生成、有效期 300 秒的对象存储签名 URL（`shusheng2.mini189.cn`），早已失效。现统一改为：

```
https://www.ilanzou.com/s/J1myTLqUr
```

三处同步更新，避免不同降级路径出现不一致：

1. `<meta http-equiv="refresh" content="0;url=...">`（无 JS / JS 被拦截时兜底）；
2. `location.replace("...")`（正常路径，不产生历史记录）；
3. 新增 `<body>` 内可点击的「继续下载」链接（meta 与脚本都被禁用时的最后兜底）。

旧域名与 `X-Amz-Signature` 已完全移除。

## 六、已知限制

1. 无真实 iPhone / iPad 真机。`data-ios-notch` 通过模拟 `env()` 计算值验证；headless Edge 桌面不实现 iOS 安全区，因此模拟中该标记为未设置（符合预期），实际几何效果需在真机确认。
2. `viewport-fit=cover` 会让内容延伸到屏幕边缘，安全区留白完全依赖 `ios-adapt.css`；若未来新增固定定位组件，需同步补充对应 inset。
3. iOS 未纳入 v8.7 的安卓渲染预算（该层仅识别 Android）。本次只针对全面屏设备关闭了最贵的全屏噪点层，其余装饰动效保留，视觉与桌面一致；如 iOS 上仍有掉帧，可另行扩展。
4. 蓝奏云短链为外部资源，其长期有效性由服务方决定；上线后建议实际访问一次确认可下载。
5. 本次未创建 Git tag / GitHub Release；如需发布 v8.8 可随时补上。

## 一、本次更新

新增一套**全站条件式光效层**，由 `assets/glow-fx.css` 与 `assets/glow-fx.js` 组成。样式表中的每一条规则（含自定义属性定义）都收在 `html[data-glow="on"]` 门控之下；该标记由脚本在完成能力与性能检测后才写入 `<html>`。**未通过检测的设备，此样式表完全是无副作用的空操作**——不改变布局、不增加绘制、不改变可读性。

### 光效清单

| 效果 | 实现 | 说明 |
|---|---|---|
| 交互式极光 | `body::before` 三层径向渐变，主光源跟随指针 | `transform` 漂移 22s 循环 + `.9s` 淡入；`pointer-events:none` |
| 暗色主题适配 | `[data-theme="dark"]` 独立色板 | 偏紫粉 / 蓝紫光源，避免暗色下过曝 |
| 导航栏流光 | `.navbar::before` 2px 渐变光带 | `background-position` 6.5s 循环，绘制面积仅 2px 高 |
| 卡片指针光晕 | 卡片 `background-image` 叠加径向渐变 | 用 `--gx/--gy` 定位；不占用任何已有伪元素 |
| 悬浮辉光 | 卡片 / 按钮 hover 时叠加柔和 `box-shadow` | 复用 `polish.css` 既有过渡曲线 |
| 标题微光 | `.hero-title` 渐变扫光 + 标题 `text-shadow` 脉动 | 9s / 5.5s 低频循环 |

与 v8.3 已有的 `fx-aurora`（`z-index:-1`）共存：v8.5 的静态光源透明度已刻意下调（亮色 `.16/.09/.07`），主要视觉增量来自**指针跟随**，避免两层极光叠加过曝。

## 二、设备门控规则

判定在 `glow-fx.js` 中按「先排除、后启用」顺序执行，任一条件命中即直接退出：

| # | 类别 | 排除条件 |
|---|---|---|
| 1 | 兼容层优先 | `data-compat="legacy"`（v8.4 Fix 已降级设备） |
| 2 | 显式关闭 | `localStorage.glowFx === 'off'` |
| 3 | 能力门槛 | 缺少 `matchMedia`、`requestAnimationFrame`、`CSS.supports`、CSS 变量/Grid 支持、`IntersectionObserver` |
| 4 | 无障碍 | `prefers-reduced-motion: reduce`、`prefers-reduced-data: reduce` |
| 5 | 网络 | `navigator.connection.saveData` 或 `effectiveType` 为 slow-2g / 2g / 3g |
| 6 | 硬件 | `hardwareConcurrency < 4`、`deviceMemory < 4`、`devicePixelRatio > 2.5` |
| 7 | 无信号时保守判定 | 核心数/内存均不可测且非 `pointer: fine`、宽度 < 1024px |
| 8 | 小屏触屏 | `pointer: coarse` 且宽度 < 768px |

运行时保护：
- 指针跟踪仅绑定**一个** `mousemove` 监听，用 `requestAnimationFrame` 合并为每帧一次读写；无 scroll / resize 循环、无定时器。
- 标签页隐藏时写入 `data-glow-paused`，CSS 暂停全部光效动画。
- `@media (prefers-reduced-motion: reduce)` 与 `@media print` 提供二次降级。

## 四、层级与可读性保障

`body::before` 位于 `z-index:0`。为避免装饰层遮挡正文，CSS 显式把 6 类顶层内容容器提升到 `z-index:1`：`#blog`、`.hero`、`.page-hero`、`.main`、`.footer`、`.wrap`。已固定定位且自带高层级的元素（`.navbar` 100、`.to-top` 90、`.theme-ctl` 50、`#loader` 9999）保持不变。

对 11 个页面逐一做了顶层容器审计：**未发现任何未被覆盖的可见顶层元素**。

## 七、已知限制与说明

1. 当前环境无真实浏览器运行时（Playwright / Puppeteer / jsdom 均不可用），视觉验证依赖静态门控分析、沙箱行为模拟与资源可达性检查，**未做像素级截图比对**。建议上线后在桌面 Chrome / Safari 上人工确认光效强度与文字对比度。
2. 光效强度为保守设定。若希望更明显，可调整 `glow-fx.css` 中 `.16/.09/.07` 三个透明度值；不建议提高 `filter: blur` 类动画，以免与 v8.3 `fx-aurora` 叠加造成 GPU 负担。
3. 手动关闭方式：在浏览器控制台执行 `localStorage.setItem('glowFx','off')` 后刷新即可永久关闭（对该浏览器）。
4. `data-glow` 在**页面加载时**判定一次；运行中若系统切换为「减少动效」，CSS 的 `@media (prefers-reduced-motion: reduce)` 会立即停用动画，但标记本身不会自动移除。

## 一、核心修复：主页 "MeowRc" 消失、仅剩 "Blog"

### 1.1 现象

首页 hero 区域只剩黑色 "Blog"，粉色渐变大字 "MeowRc" 完全不可见；四个首页浏览器变体（`index.html` / `index-apple.html` / `index-ie.html` / `index-legacy.html`）表现一致。导航栏品牌 "MeowRc Blog" 本身完整且可点击。

### 1.2 根因（v8.5 回归）

这不是 DOM 缺失，而是**层叠与动画覆盖**问题：

1. `assets/index*.css` 中 `.hero-eyebrow,.hero-subtitle,.hero-title{...opacity:0}`，标题初始不可见；
2. `.page-enter .hero-title{animation:heroUp .9s ... both, shine 8s linear infinite}` —— `heroUp` 的 `from{opacity:0} → to{opacity:1}` 配合 `both` 填充，是让标题变可见的**唯一途径**；
3. v8.5 新增的 `assets/glow-fx.css` 中 `html[data-glow="on"] .hero-title{animation:glowSweep 9s linear infinite}` 特异性为 `(0,2,1)`，高于 `.page-enter .hero-title` 的 `(0,2,0)`，**覆盖了整条 `animation` 简写**；
4. `heroUp` 被替换后 `.hero-title` 永久停留在静态 `opacity:0`；`glowSweep` 只改 `background-position`，无法恢复可见性。

`animation` 简写会重置所有动画子属性，因此叠加动画时必须并入同一条声明，不能用更高优先级的选择器另写一条。

**对照实验**（headless Edge，同一时刻）：

| 实验 | 结果 |
|---|---|
| 原始 v8.5 | 仅 "Blog"，"MeowRc" 不可见 |
| 仅禁用 `glowSweep`（`animation:none!important`） | 仍不可见（`heroUp` 一并被移除，印证根因） |
| 恢复 `heroUp` + 固定渐变位置 | **"MeowRc" 完整显示** |

### 1.3 修复

| 措施 | 文件 |
|---|---|
| 移除 glow 层对 `.hero-title` 的 `animation`、`@keyframes glowSweep` 及暂停/降级规则中的相关选择器，并加注释禁止再次覆盖 | `assets/glow-fx.css` |
| 追加 `.hero-title{opacity:1}` 静态兜底；`heroUp` 仍负责淡入，但即使动画被覆盖或 JS 失败标题仍可见 | 4 个 `assets/index*.css` |
| `@keyframes shine` 由 `to{background-position:200%/220% center}` 改为 `0%↔100%` 往返，避免渐变移出 `-webkit-text-fill-color:transparent` 的文字范围 | 4 个 `assets/index*.css` |
| 在可用性检测中加入回归断言：glow 层不得给 `.hero-title` 设 `animation`；四个 CSS 必须有静态可见兜底；`shine` 不得超过 100% | `tools/audit-usability.js` |

修复后四个首页变体均经 headless Edge 渲染复核，"MeowRc" 与 "Blog" 完整显示。

## 三、Android 7 及以上设备兼容

### 3.1 问题

8 个带 UA 分流的页面用 `CSS.supports('translate','0 64px') && CSS.supports('inset','0')` 判定"现代浏览器"。这两个特性分别需要 Chrome 104+ / 87+，导致 **Android 7（Chrome 51~56）及大量中等版本浏览器被错误导向 `index-legacy.html` 降级皮肤**，无法使用现代页面。同时 Android 7 缺少 `clamp()`、`backdrop-filter`、CSS Grid、flex `gap`、`inset` 简写。

### 3.2 改动

| 措施 | 说明 |
|---|---|
| `isModern()` 门槛重设 | 改为 `display:flex` + CSS 自定义属性 + `transform` + `matchMedia` 基线；Android 7 / Chrome 51+ 通过并走现代页，IE 仍由 `isLegacyIE()` 优先捕获，Safari 仍由 `isSafariFamily()` 捕获，更老的内核仍走 legacy 皮肤 |
| 新增 `assets/compat-android7.css` | 全部规则以 `@supports not (...)` 门控，**现代浏览器零影响**、无 UA 嗅探、无 JS |
| `clamp()` 降级 | `@supports not (font-size: clamp(...))` → 为标题/副标题提供固定字号 |
| `backdrop-filter` 降级 | 不支持时导航栏与主题控件改用不透明背景，避免半透明底透出正文、降低对比度 |
| CSS Grid 降级 | 网格容器改 `display:block` 纵向堆叠，卡片块级化并补间距 |
| `inset` 简写降级 | 装饰性绝对定位层补 `top/left/right/bottom` |
| flex/grid `gap` 降级 | 仅在同时缺 Grid 的引擎上补 `margin` |
| 渐变文字保护 | 老引擎固定 `background-position:0% 50%`，并把 `.page-enter .hero-title` 的动画收敛为 `heroUp`，避免透明文字再次消失 |
| 全站接入 | 11 个站点页面在 `</head>` 最后加载该样式表 |

**行为说明**：Android 7 因 `CSS.supports('display','grid')` 为 false，仍**不会启用 v8.5 的条件式光效**（该门控按性能设计保留），但页面布局、导航、下载、游戏入口与主题切换均完整可用。

## 六、已知限制

1. **无真实 Android 7 设备 / WebView 运行时**。兼容性验证基于 `@supports` 静态分析、`isModern()` 能力集模拟与现代浏览器渲染复核；建议在目标设备上做一次人工冒烟测试。
2. headless 截图在虚拟时间预算较短时可能停留在加载动画（`#loader`），本次复核统一使用 11s 预算；这不代表线上缺陷。
3. v8.5 光效仍按性能门控，**Android 7 不启用**，属预期降级。
4. 函数棋主体页（`online/game/hanshuqi/`）仍不接入全站光效与导航装饰层——其独立全屏 Canvas UI 含多级 `z-index`，风险高于收益；游戏板块页已补齐站点导航。
5. `ppt/1/index.html` 的外链对象存储签名 `X-Amz-Expires=300`（2026-10-31 生成）已过期，属历史遗留的外部资源时效问题，本次未改动。
6. 本次需求未要求发布 Release，因此**只提交仓库并上传本日志，未创建 Git tag / GitHub Release**；如需发布 v8.6 Release 可随时补上。
